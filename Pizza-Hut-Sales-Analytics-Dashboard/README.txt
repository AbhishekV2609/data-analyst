🍕 Pizza Hut Sales Analytics — Power BI Portfolio Project



📊 Project Overview

This project is an end-to-end Pizza Hut Sales Analytics Dashboard built using Power BI to analyze sales performance, orders, pizza products, customer activity, store/city performance, and ordering patterns.

The dashboard is designed as a portfolio project with a Pizza Hut-style dark/red visual theme and interactive filters/navigation.

Data Disclaimer: This is a synthetic Pizza Hut-style dataset created for portfolio and practice purposes. It is not internal Pizza Hut data.

🎯 Project Objectives

The main objectives of this project are:

Analyze overall sales and order performance.

Track revenue and orders month by month.

Identify the most popular pizzas.

Compare sales across pizza sizes.

Analyze sales by pizza category.

Identify top-performing cities.

Understand order patterns by day and time slot.

Provide interactive filtering for business analysis.

Build a professional Power BI dashboard suitable for a data analyst portfolio.

🧹 Data Preparation

The dataset was prepared before dashboard development.

The workflow included:

Reviewing the raw sales data.

Checking columns, data types and missing values.

Preparing customer, location and pizza dimension data.

Preparing the sales fact data.

Using Power Query for data transformation and cleaning.

Creating relationships between the tables.

Organizing the model using a Star Schema approach.

Creating calculated measures using DAX.

Building and formatting the Power BI dashboard.

📈 Dashboard Features

1. KPI Cards

The Overview dashboard contains KPI cards for important business metrics:

Total Revenue

Total Orders

Pizzas Sold

Customer-related KPI

The cards also include comparison indicators to make performance changes easier to understand.

2. Monthly Revenue & Orders Trend

A combination chart is used to analyze monthly performance.

It displays:

Monthly Revenue using columns

Total Orders using a line

This helps identify monthly sales trends and changes in order volume.

3. Orders by Day & Hour

A heatmap-style matrix was created to analyze order activity across different time slots and days.

Time slots include:

12 AM – 4 AM

4 AM – 8 AM

8 AM – 12 PM

12 PM – 4 PM

4 PM – 8 PM

8 PM – 12 AM

The color intensity represents order volume, making high and low activity periods easy to identify.

4. Revenue by Pizza Size

A column chart compares revenue generated by different pizza sizes:

Large

Medium

Regular

Pizza icons were also incorporated into the visual design to match the Pizza Hut theme.

5. Pizzas Sold by Pizza Name

A horizontal bar chart displays the top-selling pizza names.

The chart includes:

Pizza Name

Pizzas Sold

Data labels

Conditional color formatting

The visual was formatted to show the highest-selling pizzas clearly.

6. Revenue by Pizza Category

A donut chart was created to show the revenue contribution of pizza categories.

Categories include:

Signature

Classic

Veg

Supreme

The center of the donut displays the total revenue.

7. Top Performing Cities

A horizontal bar chart was created to compare city-level pizza sales.

The visual highlights the top-performing cities based on pizzas sold.

A map visual was also explored/added to provide geographic context for city-level sales.
